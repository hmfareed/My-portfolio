# 🚀 Mohammed Fareed — Developer Portfolio

A sensational, out-of-this-world digital portfolio and case study showcase for **Mohammed Fareed**, Full-Stack Software Engineer & Digital Builder based in Tamale, Ghana.

Designed with an aesthetic balancing **Apple + Linear + Vercel + award-winning creative agency** standards.

---

## ⚡ Core Features

- **Cinematic Opening Sequence**: Snappy ~1.2s reveal beam and entrance transition (persisted with session storage so it doesn't interrupt repeat page views).
- **Hero & Live Status**:
  - Availability pill ("● Available for high-impact projects").
  - Real-time GMT time clock (Tamale, Ghana).
  - Bold headline typography & magnetic call-to-action buttons.
- **Continuous Capabilities Marquee**: Smooth infinite horizontal ticker of competencies.
- **Philosophy & Foundation (01)**: Engineering principles (Architecture First, Obsession with Details, African Market Grounding).
- **Curated Systems & Case Studies (02)**:
  - Interactive category filtering: `All`, `E-Commerce`, `Systems`, `Web`.
  - **Flagship Spotlight**: **NorthMarket** (Local commerce infrastructure for Northern Ghana).
  - Production cards for **AfriCart**, **Hanara School Management**, **Kay's Packs**, **Slay by Humu**, and **NovelVerse**.
  - **Deep-Dive Case Study Modal**: Step-by-step system architecture flow, problem/solution breakdown, technical challenges, and measurable engineering outcomes.
- **Identity & Background (03)**: Interactive 3D tilt portrait powered by Framer Motion, career bio, and credentials.
- **Career Trajectory Timeline (04)**: Expandable chronology of roles and production deliveries.
- **Technical Repertoire Matrix (05)**: Deep categorical breakdown of Frontend, Backend & Systems, and DevOps competencies.
- **Interactive Physics Lab (06)**: Procedural HTML5 canvas particle gravity and repulsion simulation.
- **Currently Building Tracker**: Live sprint tracker for NorthMarket (80% milestone progress).
- **High-Impact Contact (07)**: 1-click email copy to clipboard with toast notification, interactive project inquiry form, and social links.
- **Command Palette (`Ctrl+K` / `⌘K`)**:
  - Global keyboard shortcut.
  - Search any section or project instantly.
  - Instant theme accent switcher (`Electric Lime`, `Cyber Violet`, `Warm Gold`).
- **Interactive Resume Modal**: In-app printable CV / PDF export view.
- **Desktop Custom Cursor**: Smooth reactive spring follower with contextual state morphing (`VIEW ↗`, `EXPLORE`), disabled gracefully on touch devices.

## 🛠 Tech Stack

- **Framework**: [Next.js 14](https://nextjs.org/) (App Router, Server Components)
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Animations & Gestures**: [Framer Motion](https://www.framer.com/motion/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **SEO**: Structured JSON-LD (Person Schema), OpenGraph, Twitter Cards, Semantic HTML5

## 💻 Getting Started

### 1. Prerequisites
- Node.js 18+ installed.

### 2. Run the Development Server
```bash
npm run dev
# or on Windows PowerShell:
npm.cmd run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to view your portfolio.

### 3. Build for Production
```bash
npm run build
# or on Windows PowerShell:
npm.cmd run build
```
